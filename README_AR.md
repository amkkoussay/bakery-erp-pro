# 🥖 نظام إدارة المخابز (Bakery ERP)

نظام متكامل لإدارة العمليات في المخابز، مصمم لتبسيط الإنتاج، المبيعات، والمخزون باستخدام تقنيات حديثة وواجهة مستخدم سهلة الاستخدام.

## 🌟 المميزات الرئيسية

- **نقطة البيع (POS):** واجهة سريعة وسهلة لمعالجة المبيعات المباشرة.
- **التنبؤ الذكي بالمخزون:** استخدام البيانات التاريخية للتنبؤ باحتياجات المواد الخام وتجنب النقص.
- **إدارة الإنتاج:** تتبع أوامر الإنتاج ومكونات المنتجات (BOM).
- **تقارير الربحية:** تحليل دقيق لتكاليف الإنتاج مقابل المبيعات لحساب هوامش الربح.
- **إدارة الموردين والعملاء:** سجل متكامل للتعاملات المالية والائتمانية.
- **الطلبات عبر الإنترنت:** منصة متكاملة لاستقبال وإدارة طلبات العملاء عن بُعد.

## 🏗️ البنية الهندسية (Architecture)

يعتمد المشروع على بنية **Flask** منظمة تتبع نمط (Service-Repository Pattern) لضمان سهولة الصيانة والتوسع:

![Architecture Diagram](../architecture.png)

### المكونات:
- **Blueprints (Controllers):** لمعالجة طلبات الويب وتوجيهها.
- **Services:** تحتوي على منطق العمل (Business Logic).
- **Repositories:** للتعامل المباشر مع قاعدة البيانات (Raw SQL).
- **Database:** SQLite لضمان الخفة والسرعة.

## 🛠️ التقنيات المستخدمة

- **Backend:** Python (Flask)
- **Database:** SQLite
- **Frontend:** HTML5, CSS3 (Tailwind-like custom styles), JavaScript
- **Dependencies:** Werkzeug, Jinja2

## 🚀 التشغيل السريع

1. قم بتثبيت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```

2. قم بتهيئة قاعدة البيانات (اختياري، يتم تلقائياً عند التشغيل):
   ```bash
   python run.py
   ```

3. لإضافة بيانات تجريبية:
   ```bash
   python sample_data.py
   ```

4. بيانات الدخول الافتراضية:
   - **المستخدم:** `admin`
   - **كلمة المرور:** `admin123`
